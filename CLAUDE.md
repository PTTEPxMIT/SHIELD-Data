# SHIELD-Data

Python package `shield_data`: stores and serves experimental runs from the SHIELD
hydrogen permeation rig. Sibling repos (separate clones, not submodules):
`SHIELD_DAS` records rig data, `SHIELD-toolbox` processes it.

## Commands

```bash
pip install -e ".[test,lint]"        # dev install
pytest test/                          # tests
ruff format --check .                 # BLOCKING in CI
ruff check .                          # advisory in CI (continue-on-error)
python -m mypy .                      # advisory in CI (continue-on-error)
python src/shield_data/build_db.py    # rebuild the database
```

Only `ruff format --check` and `pytest` actually fail CI. Don't treat pre-existing
`ruff check` or `mypy` output as something this branch broke — check `git stash` or
`main` before "fixing" it.

## Non-obvious rules

- `src/shield_data/shield_data.db` is a **build artifact that is nonetheless
  committed** (it ships inside the pip package). Never hand-edit it; regenerate with
  `build_db.py`. New run data and the rebuilt DB must land in the *same* commit — CI
  rejects one without the other.
- `src/shield_data/_version.py` is generated by setuptools-scm. Never edit it.
- New runs live in `run_data/YY.MM.DD_run_X_HHhMM/` with exactly
  `pressure_gauge_data.csv` and `run_metadata.json`. Full procedure: `CONTRIBUTING.md`,
  or use the `/add-run` skill.
- CSV column names carry units and spaces (`WGM701_Voltage (V)`), but the DB columns
  are lowercased and unitless (`WGM701_voltage`). `build_db.py` does that mapping.
- Ruff config lives in `pyproject.toml` (line-length 88, target py310). Don't add a
  `ruff.toml`, and don't reformat files this branch didn't touch.

## Workflow

- Never commit to `main`. Branch as `cw/<topic>`, PR, squash-merge. A hook enforces
  this; if it blocks you, branch rather than working around it.
- Run `ruff format .` and `pytest test/` before opening a PR.
- Two PR templates exist (`code_change.md`, `data_addition.md`) — pick the matching one
  via the `template=` query param when creating the PR.
